# 钢琴调律助手

一个纯前端（TypeScript + Vite）的钢琴调律网页应用。手机/电脑浏览器直接打开即可用，
所有数据保存在本地 IndexedDB，不上传任何服务器。没有麦克风时可用内置「演示模式」
（合成带非谐性的钢琴音）跑通完整流程。

## 功能模块

| 模块 | 说明 |
| --- | --- |
| 钢琴档案 | 管理多台钢琴的品牌、型号、立式/三角、位置、备注 |
| 逐音测量 | 弹一个音，FFT + DFT 精修找出前 8 个泛音，拟合该弦非谐系数 B |
| 拉伸曲线 | 十几个样本音拟合整琴 B 曲线，生成 88 键目标频率，Canvas 可视化 |
| 调律模式 | 稳定指针显示目标频率与音分偏差；齐音模式测三弦拍频判断是否调齐 |
| 工作记录 | 每次上门存档，按琴追踪音准随时间（季节）的漂移 |

## 核心算法

### 1. 泛音测频（`src/core/fft.ts`、`inharmonicity.ts`）

- 加 Hann 窗做 radix-2 FFT 得到幅度谱；
- 在预期频率附近自适应搜索每个泛音（先定 n=1、2，再用当前拟合逐峰预测下一个）；
- 谱峰先做对数幅度抛物线插值，再用 **DFT 相关 + 黄金分割搜索**精修频率，
  精度不依赖 FFT 谱线网格（单频测试误差 < 0.001 ppm）；
- 高次泛音按奈奎斯特频率自适应截断，弱泛音按幅度阈值剔除。

### 2. 非谐系数 B（Fletcher 刚性弦模型）

```
f_n = n · f1 · sqrt(1 + B·n²)
```

平方后线性化为 `(f_n/n)² = f1² + f1²·B·n²`，等权最小二乘同时解出 f1 与 B。

**验收结果（`test/inharmonicity.test.ts`，合成音设定 B 已知）：**
全音区 7 个代表键（A0 B=8e-5 到 C8 B=8e-3）拟合误差普遍 < 1%，
最差 3.6%，满足「与设定值相差不超过 5%」的要求；含 1% 噪声、三弦齐音失谐场景同样达标。

### 3. 拉伸曲线（`src/core/stretch.ts`）

- 对样本的 `ln B` 关于 midi 号做加权线性拟合，外推限幅防止端点失控；
- 以 A4 为锚，按八度类型递归（步长 12 个半音）：
  - `4:2` 低音第 4 泛音 = 高音第 2 泛音（标准）
  - `6:3` 拉伸更大、声音更明亮（极高音区第 6 泛音越奈奎斯特时自动降级 4:2）
  - `2:1` 微拉伸
- 八度内部 12 个半音按平均律比 + 律制偏移填充。

### 4. 稳定指针（`src/core/tuner-engine.ts`）

分析窗按音区自适应（低音 1.37s / 中音 0.68s / 高音 0.34s），
读数经「中值滤波抗野点 + 指数平滑（时间常数可调，默认 0.35~0.4s）」，
静音时冻结指针，避免噪声驱动。

### 5. 齐音拍频（`src/core/beats.ts`）

RBJ 窄带带通 → 绝对值检波 + 低通包络 → 滑动平均去衰减趋势 →
零填充 FFT 在 0.3~12 Hz 找拍频谱峰。输出拍频与调制深度，
拍频低于门限或调制深度过浅即判「已齐音」。

### 6. 历史律制（`src/core/temperament.ts`）

平均律、Werckmeister III、Kirnberger III、Vallotti、
四分最大音差中庸全音律、毕达哥拉斯律，以相对平均律的 12 音级音分偏移表实现。

## 开发

```bash
npm install
npm test        # 22 个单测/端到端测试（vitest）
npm run dev     # 本地开发
npm run build   # 类型检查 + 生产构建到 dist/
npm run preview # 预览构建产物
```

## 麦克风使用注意

- 需在 `localhost` 或 HTTPS 下授权麦克风；
- 已关闭浏览器的回声消除/降噪/自动增益，避免它们扭曲泛音；
- 实测环境有环境噪声时，建议单次测量多取几帧（`robustMeasure` 取中位数）。

## 目录结构

```
src/core/        纯 DSP 与领域逻辑（不依赖 DOM，可独立测试）
  fft.ts           FFT、窗函数、谱峰插值、DFT 黄金分割精修
  inharmonicity.ts 泛音搜索与 B 拟合
  stretch.ts       拉伸模型与 88 键目标频率
  beats.ts         齐音拍频检测
  temperament.ts   六种律制
  synth.ts         带非谐性的钢琴音合成器（测试 + 演示模式音源）
  tuner-engine.ts  实时调律引擎（平滑/静音门限）
  audio-engine.ts  麦克风 / 演示音源抽象
  storage.ts       IndexedDB 档案与工作记录
src/ui/          界面（无框架，原生 DOM + Canvas）
test/            vitest 测试
public/          AudioWorklet 静态资源
```
